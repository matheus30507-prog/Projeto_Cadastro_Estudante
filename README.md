# Projeto_Cadastro_Estudante

O projeto consiste no cadastro de alunos e cursos, inserindo informações necessárias para que o cadastro esteja completo.

* Tela principal:
* 
  <img width="1919" height="775" alt="Captura de tela 2026-11-19 192250" src="https://github.com/user-attachments/assets/388ec365-585b-4b94-92b6-af64132dc8d4" />

  Nesta tela o usuário tem 3 opções que são:
  - Cadastrar Estudante
  - Cadastrar Curso
  - Matricular Estudante
 
  Ele simplesmente deve clicar em qual ação deseja realizar.

* Tela de Cadastro de Estudante

  <img width="1900" height="901" alt="Captura de tela 2026-11-19 192753" src="https://github.com/user-attachments/assets/c05b3d38-9720-4525-a6ab-be5bd19b6b82" />
  <img width="1901" height="707" alt="Captura de tela 2026-11-19 192803" src="https://github.com/user-attachments/assets/b88feffa-b778-4a4f-a5ca-cdf7b70952de" />
  
  Nesta tela o usuário tem que inserir os dados do estudante que ele quer cadastrar como Nome, Data de Nascimento e o R.A que ele ira possuir. Além disso já fica embutido juntamente o cadastro do endereço logo abaixo com dados como CEP, Rua e Estado (Nesta parte o sistema vai pegar todas as informações e vai concatenar entregando o endereço por completo).
  Logo abaixo existe uma tabela mostrando todos os estudantes matriculados juntamente de suas informações.

* Tela de Cadastro de Curso
  
  <img width="1901" height="707" alt="Captura de tela 2026-11-19 192803" src="https://github.com/user-attachments/assets/e40396ee-48ab-4e98-96b1-3d207be704e1" />

  Nesta tela o usuário tem que inserir os dados do curso que ele vai cadastrar como o seu Nome, Período e o Nível de Ensino que ele vai possuir.
  Assim que o cadastro é realizado o curso vai para tabela da parte de baixo com a mesma estrutura da tabela de estudantes, só que mostrando todos os cursos que estão cadastrados.
